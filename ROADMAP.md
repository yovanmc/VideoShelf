## Definition

Windows video library + player — "AudioShelf for video" on the VideoTriage stack (.NET 10 WPF + WPF-UI + LibVLCSharp play-everything + SQLite). Multi-source → section/**creator** → series/standalone → episode; section tags + discovery; watched/unwatched + resume; lean player + PiP; **strictly read-only for library files** (mutations are DB-only: the opt-in rename tool and — from v2 — the creator-art override, which stores a path to a user-chosen image and never writes into library folders). Self-contained — all playback/thumbnails/metadata from bundled libVLC, **no external tools (ffmpeg/HandBrake) on PATH**, no network for content. **v1 (M1–M6) ✅ complete; v2 (M7–M10) creator-centric redesign + immersive player ✅ complete; v3 (M11–M15) = polish & personalization — a shell/navigation & settings restructure (kill the always-on sidebar → gear/Settings), personal/stats home, subtitle sidecars, play-queue/up-next, and the app's first owned design system + visual-consistency pass (**DARK-ONLY** — owner cut light mode 2026-06-13). v4 (M16–M21) = depth & scale — ⚠ PROVISIONAL, scoped from the future-ideas icebox: Organize (video-level tags & smart views), Power & scale (multi-select/bulk + command palette + virtualization), Library health, Player depth, an Accessibility program, and Delight/motion — to be REFINED/VALIDATED after v3 ships before any implementation.**

## Conventions (see runbook for detail)

- **Single-model, two-phase split (always Opus):** the session is **always Opus** (I drive Claude on mobile and **cannot switch models** — `/model` is a local-terminal-only picker). Opus orchestrates throughout: it brainstorms/plans, and in the build phase it delegates implementation to cheap **Sonnet subagents** (it does not hand-write production code). Opus also delegates file-reading/research to Explore/general subagents that return a digest. At every phase handoff, the finishing session pings me (PushNotification) with the exact paste-ready next-phase prompt; the ping asks only for **`/clear`** (never a `/model` switch).
- **Autonomy:** run each phase end-to-end without asking permission for safe, reversible actions; only stop for destructive/ambiguous/blocked, or the handoff ping. CI + tests + screenshots are the quality gate.
- `gh` is **not on PATH** → `& "C:\Program Files\GitHub CLI\gh.exe"`. Solution is `VideoShelf.slnx` (.NET 10 XML format). Test gate: `dotnet test VideoShelf.slnx -c Release --nologo -v q`.
- Work in **worktrees** under `.worktrees/`; **`gh pr merge` from the main repo root**, not the worktree. **Direct pushes to `main` are blocked** — every change (incl. docs/this file) ships via branch + PR.
- Commits: human author `yovanmc` + `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. **No Codex trailer.** Merge `--merge` (no squash) from Phase 2 on. The previous-phase ROADMAP/runbook status flip rides on the next phase's branch.
